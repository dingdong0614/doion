## 보정 프리셋 doion-tone-01
- 스크립트: `scripts/tone.py` (Pillow). 입력은 `public/assets/work/` 라이브 캡처, 출력은 `public/assets/tone/<slug>-<비율>.jpg`.
- 프리셋: 채도 0.9, 대비 1.04, 배경색(#F7F7F4) 쪽 따뜻한 흰 균형, 약한 선명도. 비율은 16:9(`169`), 4:5(`45`), 1:1(`11`) 세 가지만.
- 화면: 원색 그대로(2026-09-29 대표 피드백 "너무 흑백", 모바일에서는 호버 전환이 쓸모없음). 톤 통일은 이 프리셋(채도 0.94·대비 1.04·흰 균형)만.
- 해상도: 모바일 캡처는 390x844 DPR 2(780x1688). 카드·휴대폰 표시 크기에서 2배. 데스크톱 1440x900 캡처(DPR 1)는 큰 화면에 흐려 쓰지 않는다(홈 풀블리드 제거).
- 전송 형식은 next/image가 AVIF·WebP로 바꿔 보낸다(`next.config.ts` images.formats).

## 히어로 휴대폰 영상(60fps)
- `scripts/make-hero-video.py <주소>`: 실시간 녹화 대신 스크롤 위치를 부드러운 이징으로 한 프레임씩 옮기며 DPR 2 스크린샷을 찍고, `ffmpeg -framerate 60`으로 인코딩(VP9 webm + H.264 mp4). 내려갔다 같은 프레임을 거꾸로 올라오는 끊김 없는 루프(8.1초, 486프레임).
- 2026-09-29 제작본: 피티홀릭짐 공개 저장소(dingdong0614/ptholic-1)를 로컬에서 `next build && next start`로 띄워 찍음(작업 환경에서 라이브 도메인이 막힘). 외부 이미지가 빠진 칸 전까지만 스크롤(1900px). webm 744KB + mp4 425KB + 포스터 77KB.
- 라이브 주소로 다시 찍으려면 대표 PC에서 `python3 scripts/make-hero-video.py https://ptholic-1.vercel.app/` (playwright, ffmpeg 필요). 뭐무까~ 앱으로 바꾸려면 주소만 바꾼다.
- 재생: muted·loop·playsinline, load 뒤 한가할 때 붙음(첫 화면 LCP는 포스터 이미지), 화면 안에서만 재생, 정지 버튼, 움직임 줄이기면 포스터만.
