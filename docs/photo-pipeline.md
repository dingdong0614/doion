# 사진·영상 파이프라인 (2026-09-29)

## 보정 프리셋 doion-tone-01
- 스크립트: `scripts/tone.py` (Pillow). 입력은 `public/assets/work/` 라이브 캡처, 출력은 `public/assets/tone/<slug>-<비율>.jpg`.
- 프리셋: 채도 0.9, 대비 1.04, 배경색(#F7F7F4) 쪽 따뜻한 흰 균형, 약한 선명도. 비율은 16:9(`169`), 4:5(`45`), 1:1(`11`) 세 가지만.
- 화면: 무채색(`--tone-off`) 고정. 원색(`--tone-on`)은 마우스 기기에서 사진에 올렸을 때만(모바일·움직임 줄이기는 항상 무채색). 사례 원색 노출 방식은 대표 결정 항목.
- 전송 형식은 next/image가 AVIF·WebP로 바꿔 보낸다(`next.config.ts` images.formats).

## 사진 자리(촬영 전까지 실제 고객 사이트 캡처를 같은 프리셋으로 사용)
| 자리 | 파일/코드 | 교체할 촬영본 |
|---|---|---|
| 상호 띠(히어로·로더·푸터·404 푸터) | `components/SignStrip.tsx` | 고객 간판 정면을 같은 높이로 찍어 가로로 잘라 이은 사진 띠(가게당 1컷, 오후 자연광) |
| 사례 카드 조각 띠 | `app/page.tsx` `.slice` | 위 사진에서 가게별로 잘라 재사용 |
| 홈 선언문 옆 1:1 | `app/page.tsx` 실사 교체 자리 A(지금 빠둠뮤직 캡처) | 카운터 NFC 태그에 손님이 휴대폰을 대는 손 클로즈업 |
| 홈 제작 방식 4:5 | `components/Reel.tsx` 실사 교체 자리 B | 대표가 매장에서 사장님과 상담하는 장면(실제 인물, 스톡 불가) |
| 홈 사례 풀블리드 16:9 | `app/page.tsx` feature(장안설비대장 캡처. 피티홀릭 캡처는 가격 배지·주황 알약 버튼이 금지 패턴이라 뺌) | (선택) 매장 안에서 휴대폰으로 사이트를 보는 장면 |

촬영본도 `scripts/tone.py`에 넣어 같은 프리셋으로 뽑는다(한 세션처럼 보이게).

## 사례 릴(무음 루프 영상)
- 지금: `scripts/make-reel.py`가 모바일 캡처 8장을 같은 프리셋으로 4:5 틀 안에서 넘기는 영상으로 만든다(webm 약 390KB, mp4 약 600KB, 포스터 약 70KB).
- 라이브 스크롤 녹화로 바꾸기: 대표 PC에서 `node scripts/record-reel.mjs` (playwright, ffmpeg 필요). 결과가 2MB를 넘으면 CRF를 올린다.
- 순서: 장안설비대장부터(포스터에 금지 패턴이 없도록). 영상도 CSS로 무채색.
- 재생 규칙: preload none, 가까워지면 포스터, 화면 안에서만 재생, 정지 버튼, 움직임 줄이기면 정지.

## 더 이상 쓰지 않는 파일
