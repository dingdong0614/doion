# 상담 신청 수신·처리

## 흐름

`/contact` 폼 → `POST /api/contact`(서버 검증·honeypot·횟수 제한) → 메일 발송
- `RESEND_API_KEY`가 있으면: 서버가 Resend로 **ceo@doion.co.kr**에 발송
- 없으면(현재): 브라우저가 Web3Forms로 발송. 수신 주소는 Web3Forms 키에 등록된 메일(기존 사이트와 동일). ceo@로 받으려면 web3forms.com에서 ceo@doion.co.kr로 키를 재발급해 `NEXT_PUBLIC_WEB3FORMS_KEY`에 넣거나 Resend를 연결

- 수집 항목: 매장 이름, 담당자 이름, 연락처, 업종, 문의 내용(선택), 필수 동의
- 메일 제목: `[상담 신청] 매장 이름 (업종)`
- 기존 사이트의 이메일 칸과 뉴스레터 선택 동의는 뺐습니다. 연락은 전화로 하고, 뉴스레터는 운영하지 않기 때문입니다.

## 스팸·남용 방지

- 화면에 안 보이는 칸(honeypot)이 채워져 있으면 성공처럼 응답하고 버립니다.
- IP당 10분에 5회까지만 받습니다(KV 연결 시 모든 서버 인스턴스에 공통 적용).
- 문의 내용은 메일 HTML에 넣을 때 이스케이프합니다. 문의 내용은 데이터로만 다루고, 명령으로 해석하는 로직은 없습니다.

## 처리 원칙 (개인정보처리방침과 일치)

- 상담 처리가 끝나고 3개월이 지나면 메일함에서 해당 신청 메일을 삭제합니다.
- 계약으로 이어지면 계약 관련 기록은 법정 기간 동안 따로 보관합니다.

## 메일이 안 올 때

1. Vercel → 프로젝트 → Logs에서 `[contact]`를 검색합니다.
2. `resend failed 403`이면 Resend에서 발신 도메인 인증이 됐는지 확인합니다.
3. 사용자 화면에 "지금 온라인 접수가 안 됩니다"가 나오면 `RESEND_API_KEY`가 비어 있는 것입니다.
