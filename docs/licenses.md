| 항목 | 출처 | 라이선스 | 상태 |
|---|---|---|---|
| Wanted Sans Variable (제목·본문) | wanteddev/wanted-sans (npm 1.0.3) | SIL OFL 1.1, `app/fonts/wanted/wanted-sans.css` 머리 주석에 고지 | ✓ |
| Lucide 아이콘 | lucide-react | ISC | ✓ |
