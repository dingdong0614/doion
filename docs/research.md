조사일: 2026-09-16. 30곳 모두 실제 브라우저로 열어 데스크톱 1440×900과 모바일 390×844 화면을 찍었습니다. 폰트 크기, 여백, 버튼, 배경색은 `getComputedStyle`로 잰 값입니다. 스크린샷을 보고 판단한 값에는 "추정"이라고 적었습니다.

## 1. 결론: 지금 시안이 구려 보이는 이유 (30곳과 비교)

| # | 지금 시안 | 30곳의 실제 | 근거 |
|---|---|---|---|
| 1 | 제목을 800 굵기로 두껍게 씀 | 고급 쪽은 **300~500으로 얇게** 쓰고 크기로 존재감을 냄 | Squarespace h1 64px/300, Shopify 96px/300, Stripe 48px/300, Square 세리프 400, Cursor 26px/400, Vercel 64px/400. 굵은 700~800은 imweb·배민 같은 "한국 SaaS 톤" |
| 2 | CSS로 그린 노트북·휴대폰 목업 | **목업 없이 스크린샷을 그대로**(radius 4~18px, 그림자 0) 크게 쓰거나, 사진 속 실제 기기로 보여줌 | Squarespace·Webflow·Framer·Shopify·imweb 모두 목업 없음. 기기를 쓰는 곳은 실사 사진 속 손+기기(토스플레이스, Shopify, Square) |
| 3 | 네이비 + 골드 + 로고 파랑 + 사례 카드마다 브랜드색 8개 | **무채색 + 포인트 1색**. 색은 사진과 결과물이 담당 | 포인트 색이 10개가 넘는 곳은 배민 하나이고, 가장 "싸 보이는" 곳도 배민 |
| 4 | 실사 사진 0장 | 30곳 중 대부분이 **실제 사람·가게·손 사진**을 첫 화면에 둠 | Square(이발소·주방), Squarespace(이발), 토스플레이스(카운터의 손), 당근·카카오뱅크(생활 사진), Shopify(매장) |
| 5 | 섹션마다 "굵은 제목 + 카드 묶음" 반복 | 제목은 **2톤 한 문단**(진한 핵심 + 회색 부연), 구획은 **1px 선이나 면 색 전환**으로만 | 2톤 제목: Stripe·Linear·Vercel·Raycast·Cursor·Figma·Shopify. 1px 선: Stripe 138개, Linear 146개, Cursor 130개 |
| 6 | 사례를 설명하는 카드 하나하나 | **양으로 압도**하되, 캡션은 "이름 · 업종" 한 줄 | Framer 벤토, Webflow 스트립, Squarespace 벽. 동네 가게 대상은 imweb처럼 업종 라벨이 효과적 |

요약하면 지금 시안은 "두꺼운 글씨 + 그린 목업 + 색 많음 + 사진 없음" 조합이라 AI가 만든 SaaS 랜딩처럼 보입니다. 30곳의 공통 답은 **"얇고 큰 글씨 + 실사 사진 + 맨 스크린샷 + 무채색에 포인트 1색"**입니다.

## 2. 30곳 공통 패턴 (실측 수치)

### 타이포
- **히어로 제목**: 데스크톱 48~96px, 모바일 34~56px. 자간 -0.02~-0.06em, 행간 1.0~1.15.
  - 굵기는 고급형 300~500, 소상공인·한국형 700~800 (카카오뱅크 800, 토스 700).
- **한글 제목 실측**: Squarespace 64/300/-0.06em, Notion 96/600/-0.048em, 카카오뱅크 Pretendard 89/800/-0.01em·행간 1.3, 토스플레이스 56/700/행간 1.3.
- **본문**: 15~18px, 행간 1.5~1.6. 한글은 `word-break: keep-all` 필수 (Airbnb는 이게 없어 "호/스트"처럼 단어 중간에서 끊김).
- **폰트 수**: 1~2종. 제목 세리프 400 + 본문 산세리프 조합이 따뜻하면서 고급스러움 (Square, Mailchimp, Cursor 보조).

### 색·리듬
- **배경**: 흰색 / 오프화이트(#F5F5F7, #F7F7F4, #F2F4F6) / 짙은 무채색(#08090A, #231E15 갈색, #02090A 청록) 셋 중에서 고름.
- **포인트 색 1개**: Apple 파랑, Stripe 보라, Square 파랑, Mailchimp 노랑, Airbnb 분홍, Cursor 주황(링크 전용).
- **섹션 구분**: 배경 교차(Apple, Wix, Square), 1px 선(Stripe, Linear, 현대카드, Work & Co), 12~24px 흰 틈(Apple, 삼성) 중 하나. **그림자로 구분하는 곳은 0곳.**
- **섹션 여백**: 80~130px로 고정 (Linear 128, Webflow 80, Figma 80, Square 120, Framer 120).
- **글로우·블러 블롭을 쓰는 곳**: Framer, Raycast, imweb 버튼뿐. Squarespace·Shopify·Apple·Stripe는 안 씀.

### 사례·결과물 보여주는 방식 (가장 중요)
| 방식 | 사이트 | 구성 |
|---|---|---|
| 부채꼴 3장 | Squarespace, imweb | 가운데 정면 660px, 양옆 `rotateY` 기울여 화면 밖으로 잘림. 목업 없음 |
| 벤토 모자이크 | Framer | 가로·세로 칸 크기를 섞고 간격 10px, radius 16px. 사이트 첫 화면을 꽉 채워 자르고 캡션 없음 |
| 비스듬한 스트립 | Webflow | 7장을 같은 각도로 기울여 겹침. 캡션 없음 |
| 느린 가로 마퀴 | Shopify, Wix, imweb | 높이 통일(376px). Shopify는 **사이트 화면과 매장 현장 사진을 번갈아** 배치 |
| 잘리는 실물 화면 | Linear, Vercel | 컨테이너 폭 그대로 두고 아래를 페이드(`mask-image`)하거나 뷰포트에서 자름 |
| 사진 패널 위 창 | Cursor | 풍경화 배경 위에 앱 창을 얹음 |
| 거대 텍스트 리스트 | Locomotive, Work & Co | 이미지 없이 상호명 110px + 1px 선 |

### 소상공인 대상에서만 보이는 것
- **"어떤 업종이세요?" 칩** (토스플레이스): 높이 80px 알약, #F2F4F6, 22px. 마지막 칩은 "빠른 상담 받기".
- **사장님 실명 + 말투 그대로 인용** (당근, 토스플레이스): "키오스크 덕분에 객단가가 높아지고…"
- **전화 상담 버튼을 온라인 신청과 같은 크기로 나란히** (배민)
- **모바일 하단 고정 CTA** (Airbnb 전체 폭 버튼, 토스플레이스 알약 상담 바, Square 상단 CTA 바)
- **가격·보장을 숨기지 않고, 조건은 작은 글씨로 정직하게** (Airbnb 에어커버, Mailchimp 플랜 카드)
- **숫자에 기준일·각주** ("2025년 1월 기준" 당근, 각주 Mailchimp)

### CTA
- **규격을 하나로 통일**: 알약형 높이 44~60px. 채움 1개 + 약한 보조 1개(외곽선, 연한 틴트, 밑줄 링크).
- **버튼 아래 불안 해소 한 줄**: Squarespace "결제 정보 없이 무료 체험", Raycast 모노 캡션.
- **섹션 안 이동은 텍스트 링크**: "~보기 →" (Figma, Vercel, 삼성).

### 모션
- 30곳 모두 **영상 히어로, 느린 마퀴, 캐러셀(일시정지 버튼 포함), sticky 정도**만 씀.
- **따라 하면 안 되는 것**:
  - 토스·토스플레이스·당근의 스크롤 연동 장면 (문서 높이 5만 px, 사실상 하이재킹)
  - basement·Locomotive의 WebGL·Lenis
  - Ramotion·Instrument의 자동재생 영상 다수 (약한 폰에서 무거움)

## 3. doion 방향 제안 (하나로 정리)

**컨셉: "사장님 가게가 주인공, doion은 조용한 액자"**

### 3-1. 토큰
| 항목 | 값 | 출처 |
|---|---|---|
| 배경 | 웜 오프화이트 `#F7F7F4`, 카드 `#EFEEEA`, 한두 구간만 짙은 웜블랙 `#1B1A17` | Cursor, Mailchimp, Squarespace |
| 글자 | `#1B1A17` / 보조 `rgba(27,26,23,.55)` | Cursor |
| 포인트 | **1색만**: 로고 다이아몬드 파랑 `#2F5FA8` (골드 폐기) | 30곳 공통 "포인트 1색" |
| 제목 | Wanted Sans **400~500**, 데스크톱 `clamp(40px, 6vw, 88px)`, 자간 -0.04em, 행간 1.05 | Squarespace, Shopify, Vercel |
| 2톤 제목 | `<h2>핵심 한 문장. <span class="muted">부연 설명.</span></h2>` | Stripe, Linear, Figma, Shopify |
| 본문 | 17px / 1.6, `keep-all` | 공통 |
| 구획 | 1px 선 `rgba(27,26,23,.1)` + 섹션 여백 112px, 그림자 0 | Stripe, Linear |
| 버튼 | 알약 52px. 채움(웜블랙) 1개 + 연한 틴트 보조. 아래에 불안 해소 한 줄 | Cursor, Notion, Squarespace |

### 3-2. 홈 구성 (위→아래)
1. **히어로**
   - 풀폭 실사 사진(동네 가게 카운터, 사장님 손 + 휴대폰 + NFC 태그)
   - 가운데 얇은 제목 한 줄 + CTA 하나 + "상담 무료 · 계약 전 비용 없음"
   - 하단에 **실제 고객 사이트 스크린샷 3장 부채꼴**(목업 없음)이 올라옴
   - 출처: Square, Squarespace
2. **"어떤 업종이세요?" 칩**
   - 헬스장 / 뷰티 / 학원 / 음식점 / 교회 / 요양원 / 빠른 상담
   - 누르면 해당 사례로 이동
   - 출처: 토스플레이스
3. **사례 벤토 모자이크**
   - 맨 스크린샷을 칸 크기를 섞어 배치(간격 10px, radius 16px)
   - 캡션은 "상호 · 업종" 한 줄만
   - 출처: Framer, imweb
4. **2톤 한 문단**: "사장님은 장사만 하세요. <회색>수정·사진 교체·태그 관리는 매달 저희가 합니다.</회색>" (출처: Figma, Shopify)
5. **NFC/QR 한 구간 (짙은 웜블랙 배경)**: 실사 사진(태그에 폰 대는 손) + 3단계 설명 (출처: Square 기능 아코디언)
6. **사장님 이야기 1~2개**: 사진 + 실명·말투 인용 + "○○ 관장님 이야기 →" (출처: 당근, 토스플레이스). **실제 인용을 받은 경우에만** 넣음.
7. **가격**: 제작 3안 + 관리 3안 + 보장 체크리스트("관리비 1년 고정 ✓ 도메인 명의 사장님 소유 ✓"), 조건은 작은 글씨 (출처: Airbnb, Mailchimp)
8. **마무리 CTA**: 전화 상담과 온라인 신청을 같은 크기로 나란히 (출처: 배민)
9. **모바일**: 하단 고정 바 [전화][상담 신청] 반반 (출처: Airbnb, 배민)

### 3-3. 버릴 것
- CSS로 그린 노트북·휴대폰 목업
- 800 굵기 제목
- 골드
- 사례 카드마다 다른 브랜드 배경색
- 스크롤 연동 장면
- 자동재생 영상 여러 개
- 글로우·블러

## 4. 막히는 지점: 실사 사진

30곳이 고급스러워 보이는 가장 큰 이유가 **실제 사람·가게 사진**인데, 지금 doion에는 한 장도 없습니다. 필요한 사진은 5~8장입니다.
- 매장 카운터에 붙은 NFC/QR 태그
- 휴대폰을 태그에 대는 손
- 사장님이 휴대폰으로 자기 가게 사이트를 보는 모습
- 고객 매장 전경 2~3곳 (피티홀릭짐, 뭐무까 제휴 가게 등, 공개 동의 필요)
- 대표 상담 장면 1장

선택지:
1. 직접 촬영 (가장 좋음, 스마트폰도 가능)
2. 고객 매장 협조 촬영
3. 임시로 무료 스톡(Unsplash) 사용 → 나중에 교체 (가짜 후기처럼 보이지 않게 "사례" 옆에는 쓰지 않음)
